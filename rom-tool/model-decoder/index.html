Step 2 · Decode model geometry

The first decoder pass interprets N64 vertex data and F3DEX2 triangle/display-list commands using the published object offset catalog. It exports separate named mesh groups into one OBJ.

What this version does not decode yet

Textures/materials, the complete animated skeleton hierarchy, animation clips, and game-specific display-list state are not exported. Some display-list commands may be skipped; check the diagnostic report before treating the OBJ as complete.
