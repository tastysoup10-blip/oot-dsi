What this version extracts

Individual DMA files, including raw files and Yaz0-compressed files (automatically decompressed). The retail ROM does not contain friendly filenames, so files are shown by index and address. This version does not yet identify Link's object or convert N64 display lists into a DSi mesh.

Nothing is saved by this page. Keep extracted files on your device; do not commit ROM data or extracted assets to the public repository.
