Model Converter

Convert a simple Wavefront OBJ mesh into a C header that can be compiled into the DSi player prototype.

Local processing

Your model file stays in this browser. Nothing is uploaded. This first version converts geometry only—no textures, materials, or skeletal weights.

DSi limits

This converter caps output at 500 triangles as a conservative starting point. The DS 3D engine has a 6,144-vertex-per-frame hardware limit shared by the whole scene. Keep models low-poly.

How to use the result
  1. Download model_mesh.h.
  2. Place it in dsi-player-movement/source/.
  3. Include it in main.c and call draw_imported_model() where the placeholder player is drawn.

The header draws a single-color mesh. It is not a Link model extractor; use a model you created or are allowed to use.
