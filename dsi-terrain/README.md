# DSi Terrain Test

A third native Nintendo DS/DSi graphics milestone for the Ocarina of Time port research.

## What it tests

- A procedurally generated, colored terrain grid (12 x 12 quads)
- Rendering terrain and a textured 3D object in the same scene
- Camera movement with the D-pad
- Camera height with X/Y (the shoulder buttons are not required)
- A resets the camera; START exits

No Ocarina of Time ROM, extracted assets, or copyrighted game data are included. The terrain and cube texture are generated by the program.

## Build

The GitHub Actions workflow builds this alongside the earlier graphics tests. Download the `oot-dsi-3d-test` artifact and look inside the `dsi-terrain/` folder for `oot_dsi_terrain_test.nds`.

A successful build confirms compilation only. Test the resulting ROM on actual DSi hardware to confirm rendering and controls.
